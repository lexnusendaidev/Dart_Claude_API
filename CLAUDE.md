# Project Instructions

Follow these repository standards for all coding-agent work.

- Start with the broad standards in `.claude/rules/core-standards.md`.
- Apply backend rules when working in .NET, C#, SQL, EF Core, API, Business, Data, Infrastructure, Models, Common, Contracts, or Tests projects.
- Apply front-end rules when working in React, TypeScript, Vite, React Router, React Query, SignalR client code, forms, UI, or tests.
- Apply testing rules whenever creating, changing, or reviewing tests.
- Do not duplicate rule content in new files. Add new rules to the most specific existing rule file.
- Use `.claude/commands/*.md` for on-demand, multi-step workflows (for example adding a feature end-to-end).
